# Network Analysis: Arms Trade (Community Detection)

This project applies network analysis methods to global arms trade data to identify communities of countries using graph-based community detection algorithms.

**Authors:** Alexandra Rui, Polina Mishulina  
**Affiliation:** LMU Munich

## Methods
- Network construction from SIPRI Arms Transfer Database
- Community detection (Louvain / modularity-based)
- Visualisation of trade network structure

## Stack
Python · NetworkX · pandas · matplotlib
